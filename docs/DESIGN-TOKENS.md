## 구조 메모

- 라우트: 운영 모듈 = `#/hermes/...` (workbench / activity / task / flow / setting)
- 상단 내비: 대시보드 · 분석 · 사용자 · 운영 · 설정 센터 · 데이터 · 도구
- 운영 드롭다운: 운영 일정(워크스페이스·운영 캠페인) / 사용자 도달(운영 작업·플로우 캔버스) / 기본 설정(운영 설정)
- 운영 설정 사이드바: 채널 · 피로도 제어 · 승인자 · 화이트리스트 · 분석 설정 · 현지화 · 클라이언트 파라미터 · 설정 테이블 관리
- 채널 탭: Webhook 채널 · 메시지 푸시 · 클라이언트 채널 · 서드파티 플랫폼
- 채널 목록 테이블 컬럼: 채널 이름 · 생성자 · 마지막 수정자 · 피로도 제어 · 채널 스위치 · 작업

## 운영 작업 생성 — 실측 구조 (2026-08-03 2차 측정)

### 진입 플로우 (내 목업에 없던 단계)
```
운영 작업 목록 → [＋ 작업 생성]
  → ① 모달 「도달 방식 선택」 (Webhook 도달 / 메시지 푸시 / 클라이언트 도달 3개 카드)
      · 채널이 없는 방식은 회색 비활성 + [채널] 바로가기 링크 노출
  → ② 모달 「Webhook 도달 · 도달 채널 선택」 (검색 + 채널 리스트, 이전/확인)
  → ③ 작성 화면 (#/hermes/task/create)
```

### 작성 화면 = 전체화면 + 좌측 스테퍼
- 상단 바: `‹` 뒤로 · 채널 타입 배지(Webhook) · **작업 이름 입력(80자 이내)** · `UTC-8` · [초안 저장] [저장 후 제출]
- 좌측: 세로 스테퍼 6단계 (현재 단계 강조 + 요약값 표시)
- 우측: 각 섹션이 카드로 세로 나열 (스크롤 연동)

### 6개 섹션과 내용
| # | 섹션 | 구성 |
|---|---|---|
| 1 | **푸시 시점** | 푸시 타입 7종 타일 — 시간 지정-1회 / 시간 지정-반복 / 수동 / 트리거-A 완료 / 트리거-A 완료 후 B 완료 / 트리거-A 완료 후 B 미완료 / 트리거-커스텀 · 푸시 시간 · 승인 시간 초과(자동 종료 / 승인 후 바로 푸시) |
| 2 | **타겟 사용자** | 커스텀 그룹 / 기존 토글 · 사용자 충족 조건 · 사용자 행동 조건 · 사용자 제외 조건 (AND) · **예상 인원 + [예측] 버튼** |
| 3 | **푸시 설정** | **A/B 테스트 활성화** 토글 · 도달 채널 · 피로도 제어 · 화이트리스트(멤버 선택) |
| 4 | **푸시 콘텐츠** | 기본 언어 탭 · 템플릿 필드 입력(0/128) · **[테스트 전송]** |
| 5 | **목표 설정** | 주요 목표 · 설명 추가 · **목표 기간**("성공 수신 후 N일 내 아래 이벤트 실행 시 목표 달성") · 구체적인 규칙 · 조건 추가 |
| 6 | **지표 설정** | 푸시 성공 등 지표 선택 |

### 추가 확인 사항
- 작업 이름은 상단 바에 있음(본문 아님)
- 시간대 표시가 상단에 고정(`UTC-8`)
- 저장은 **초안 저장**과 **저장 후 제출** 2단계

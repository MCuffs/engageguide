SMS는 AE가 직접 제공하지 않습니다. Webhook으로 자사 서버를 거쳐 SMS 사업자에 연결해야 합니다.

자주 하는 실수

  • 필드명 불일치 — 컨텐츠 템플릿의 필드명이 곧 서버가 읽을 JSON 키입니다. 자동 매핑이 아니라 이름 약속이라, 한쪽만 바꾸면 값이 조용히 무시됩니다.
  • 이벤트명 3곳 불일치 — 앱 코드 · 채널의 도달 퍼널 설정 · 트래킹 플랜이 모두 같아야 클릭이 집계됩니다.
  • 멱등성 누락 — message_id 기준 중복 차단이 없으면 재시도 시 보상이 이중 지급됩니다.
  • URL 오해 — 채널의 URL은 플랫폼이 발급하는 값이 아니라, 자사 서버를 만들어야 생기는 값입니다.

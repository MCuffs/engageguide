# Engage Guide

ThinkingAI **Agentic Engine(AE)** 운영 모듈 · 설정 센터 도입을 위한 학습 자료와 시뮬레이터.

실제 AE 콘솔(`ae-demo.thinkingdata.io`)의 DOM과 computed style을 직접 측정해 UI를 재현했고, 각 기능마다 **왜 필요한지 · 언제 쓰는지 · 개발팀이 할 일 · 사업팀이 할 일**을 붙였습니다.

## Engagement OS — 무엇을 할 수 있나

AE 콘솔을 그대로 옮긴 **연습용 환경**입니다. 실제 계정 없이 채널을 만들고 발송해 보며 개념을 익힙니다.

### 1. 콘솔 재현
- 상단 가로 내비(56px) + 좌측 사이드바(260px) 2단 구조
- 운영 드롭다운 3그룹 — 운영 일정 / 사용자 도달 / 기본 설정
- 채널 생성은 **우측 드로어 992px** (실물과 동일)
- 작업 생성은 **도달 방식 선택 → 채널 선택 → 6섹션 작성 화면** 3단계

### 2. 도입 가이드 (스포트라이트 투어)
상단 **「▶ 도입 가이드」** 버튼으로 실행합니다.

- **운영 작업 19단계** — 채널 구축 → 안전장치 → 작업 생성 → 발송 → 측정
- **설정 센터 11단계** — 항목 정의 → 파라미터 → 배포 경로 → 전략 → 측정

해당 요소만 밝게 남기고 나머지는 어둡게 처리하며, 각 단계마다 **개발팀 / 사업팀** 할 일이 표시됩니다.
`Enter` 또는 우측 하단 **다음** 버튼으로 진행, `←/→` 이동, `Esc` 종료.

### 3. 기능별 도움말
기능명 옆 작은 **ⓘ** 마커에 마우스를 올리면 4단 설명이 뜹니다 — 왜 필요 / 언제 / 개발팀 / 사업팀. 44개 항목에 적용.

### 4. 테스트 단말
우측에 게임(Polaris) · 이커머스(데일리마켓) 두 앱이 있는 휴대폰이 붙어 있습니다.

| 확인할 수 있는 것 | 방법 |
|---|---|
| 채널별 도달 차이 | 잠금화면 상태에서 각 채널로 발송 — 푸시는 도달, 클라이언트는 실패, Webhook은 우편함에 적재 |
| 피로도 제어 | 푸시를 3회 연속 발송 — 3회째가 유저 단위 한도로 차단 |
| 방식 vs 패스스루 | 「앱 열기」와 「지정 페이지 열기」의 클릭 후 이동 차이 |
| 설정 센터 즉시 반영 | `shop_discount` 값을 바꾸면 상품 가격이 바로 변경 |
| 도달 퍼널 | 예약 → 실제 발송 → 도달 → 클릭 단계별 집계 |

## 핵심 개념 요약

### 채널 3종
| 채널 | 서버 개발 | 닿는 대상 | 용도 |
|---|---|---|---|
| **메시지 푸시** (FCM/APNs/Aurora) | 불필요 | 앱 밖 유저 포함 | 복귀 유도 — 주력 |
| **클라이언트** | 불필요 | 앱 실행 중 유저만 | 온보딩·이탈 방지 |
| **Webhook** | **필요 (약 4 man-day)** | 서버 구현에 따름 | 인게임 메일·쿠폰 지급 |

> SMS는 AE가 직접 제공하지 않습니다. Webhook으로 자사 서버를 거쳐 SMS 사업자에 연결해야 합니다.

### 운영 모듈 vs 설정 센터
| | 운영 모듈 | 설정 센터 |
|---|---|---|
| 산출물 | 푸시 · 팝업 · 화면 렌더링 | 서비스 구성 · 가격 · 기능 |
| 시간성 | **1회성** (발송하면 끝) | **지속** (배포된 동안 적용) |
| 쓸 때 | 앱 밖 도달, 1회성 지급 | 밸런스 조정, 기능 변경 |

### 자주 하는 실수
- **필드명 불일치** — 컨텐츠 템플릿의 필드명 = 서버가 읽을 JSON 키입니다. 자동 매핑이 아니라 이름 약속이라, 한쪽만 바꾸면 값이 조용히 무시됩니다.
- **이벤트명 3곳 불일치** — 앱 코드 · 채널의 도달 퍼널 설정 · 트래킹 플랜 세 곳이 모두 같아야 클릭이 집계됩니다.
- **멱등성 누락** — `message_id` 기준 중복 차단이 없으면 재시도 시 보상이 이중 지급됩니다.
- **URL 오해** — 채널의 URL은 플랫폼이 발급하는 값이 아니라 자사 서버가 만들어야 생기는 값입니다.

## 참고

- 시뮬레이터의 데이터는 모두 브라우저 메모리에만 존재합니다. 실제 AE 계정이나 서버에 연결되지 않습니다.
- 화면 구조와 디자인 토큰은 2026-08-03 기준 데모 환경에서 측정했습니다. 제품 업데이트에 따라 달라질 수 있습니다.
- 아직 재현하지 않은 화면: 워크스페이스, 플로우 캔버스, A/B 실험 리포트.
